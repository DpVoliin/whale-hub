# 参与进来：版本策略 + 可以认领的任务

> 这个文件有两个用途：① 说清"什么时候算 1.0"（免得外部以为版本策略模糊）；
> ② 列出一批**有证据、有验收标准**的小任务 —— 每条都可以直接开成一个 issue，标上 `good first issue`。

---

## 一、版本策略（为什么是 0.1.x，什么时候到 1.0）

**我们刻意不按 SemVer 走 0.x。** 理由：这套系统的使用方式是"你自己部署、数据在你机器上"，
升级的代价不是"兼容性破坏"，而是**你要不要花十分钟跑一次部署**。
0.1.x 的意思是「**接口可能变，但我会在 CHANGELOG 里写清楚**」——
第三位递增是刻意的：一次改动 = 一个可回退的点，发布节奏细、回滚粒度也细。

**到 1.0 的门槛（满足全部三条才升）：**

| 门槛 | 现状 | 怎么算达成 |
|---|---|---|
| 至少 3 个**外部真实用户**连续用满 1 个月 | 0 | 有 issue/讨论里能数出来的真实部署 |
| 健康数据 + Android 采集器在真机上连续 30 天无数据丢失 | 未验证 | 靠采集器的重试队列 + 用户反馈 |
| 语音/文字出口与提醒决策在两条以上真机上稳定 | 部分 | 挂件 + 采集器都跑满一个月 |

到 1.0 之后**才**开始承诺"小版本不破坏接口"。在那之前，请始终用 CHANGELOG 决定要不要升。

## 二·五、可以认领的任务（都带证据与验收标准）

> 认领方式：在对应 issue 下留言即可；没有 issue 就自己开一个，标题照抄下表。
> 每个任务都**不需要你读懂整个系统**，改完跑 `python3 -m unittest discover tests` 就好。

### 4. 文档英译（**按文件认领，一份一个 issue**）　`good first issue`
- **证据**：`docs/` 下的技术文档全部是中文（14 份；本文件除外）
- **做什么**：约定译名为 `docs/<原名>.en.md`（例如 `docs/PRIVACY.en.md`），开头加一行
  `> English translation of <原名>. 中文原文以 <原名> 为准。`
- **优先级建议**：`PRIVACY.md` → `ARCHITECTURE.md` → `SCHEMA.md` → `DEPLOY-GUIDE.md`（这四份对外最有用）
- **验收**：与中文原文逐节对应、不增删技术结论；专有名词保持一致（见文末词表）

### 6. 更多出口通道（飞书 / Bark / ntfy）　`help wanted`
- **证据**：`hub/src/whalecare/93_channels.py` 已把"出口"抽成一层，但只接了少量通道
- **做什么**：照现有通道的样子加一个（含失败重试与限流）
- **验收**：加一个测试证明"通道失败不阻塞其他通道"；文档补一节

### 7. Health Connect 作为可选数据源　`help wanted`（大一点）
- **证据**：README 路线图里有；目前健康数据靠通知监听，覆盖不到"没有通知的测量"
- **做什么**：采集器加 Health Connect 读取（**可选、默认关**，与现有隐私开关同规格）
- **验收**：默认关闭时零读取；开启后与通知监听的数据**去重**不重复计数

### 8. F-Droid 收录　`help wanted`（大一点）
- **证据**：`docs/FDROID.md` 已备好材料与自查表
- **做什么**：按那份文档提交 fdroiddata MR，处理维护者的提问
- **验收**：App 出现在 F-Droid（或拿到明确的阻塞原因，写回文档）

## 三、标签约定

| 标签 | 含义 |
|---|---|
| `good first issue` | 不需要理解整个系统；有一条明确验收标准 |
| `help wanted` | 有价值但需要一些上下文（上面第 6/7/8 条）|
| `docs` | 只动文档 |
| `privacy` | 涉及数据进出模型的边界 —— **需要额外写一节"为什么这不会扩大暴露面"** |

## 四、参与前的三条硬规矩（和代码无关，但会卡住你的 PR）

1. **改片段必须一起重新合并**：改 `hub/src/whalecare/*.py` 后跑 `python3 hub/tools/build_single.py`
   并把 `hub/hub.py` 一起提交 —— 只改一个 CI 必红（"逐字节等价"那一步）
2. **提交前跑 lint 的两步**（见 `CONTRIBUTING.md` 的表）：产物严格、片段用专用配置
3. **不要往仓库里带**：服务器地址 / token / 你的真实数据样例 / 带版权风险的美术素材
   （CI 里有一条脱敏体检，命中就直接拒绝推送）
