# 2 分钟 demo 视频：分镜脚本（照这个录）

> 结论先给：**最强的钩子不是"她能聊天"，而是"她主动发来一条有用的消息"**。
> 所以视频**必须**在 15 秒内出现这一幕，不要从"我做了个系统"讲起。

**总时长 2:00 · 竖屏 1080×1920（手机端观感最好）· 无解说也可（打字幕）**

| 时间 | 画面 | 字幕/旁白 | 要点 |
|---|---|---|---|
| 0:00–0:08 | 手机锁屏 → 微信弹出她的消息：`（算了算）明日方舟 72 分钟，比昨天多 20 分钟；明早 8 点那节课在 1 号楼 201，别熬。` | "她不是聊天框。她自己找我。" | **第一幕就是杀招**：具体数字 + 具体课 + 劝睡 |
| 0:08–0:20 | 切到课程表 App（那节课确实在）| "她怎么知道我有课？" | 制造疑问 → 好奇心 |
| 0:20–0:40 | 画数据流：手机 → 你的服务器 → 微信（可录终端里 `hubctl status`）| "数据从手机到我家里的服务器，没经过任何第三方" | **隐私是核心卖点**，不是技术细节 |
| 0:40–1:00 | 电脑上打开 `/llm-preview`，高亮"会发给模型的"与"永远看不到的"两栏 | "进模型前，App 名、通知原文、位置全被剥掉 —— 这份清单你能随时自己核对" | 这一屏最有说服力，别快进 |
| 1:00–1:20 | 挂件在桌面上打盹 / 点一下换表情 / 气泡说话 | "桌面也有一个，她在那儿守着" | 情绪价值 |
| 1:20–1:40 | 工地风镜头：`git clone` → `python3 hub/hub.py` → 出现 token 打码的启动行；再 `docker compose up -d` | "四步，半小时，4C4G 就够" | 降低"我做不到"的心理门槛 |
| 1:40–1:55 | 滚动 GitHub README（徽章 + 30 秒上手那段）| "MIT 开源，代码你可以自己读一遍" | 信任收尾 |
| 1:55–2:00 | 黑屏白字 | "她住在我自己的机器里。" + 仓库地址 | 记忆点 |

## 录制前准备（10 分钟）

1. 手机**清通知栏**（只留她那一条），亮度调到 80%
2. 微信里那条消息**提前让她发出来**（用 `hubctl` 或直接等她聊；别用假截图，观众看得出来）
3. 终端 **字体调大**（≥16pt）、深色主题、窗口别满屏
4. 关掉手机横幅通知打扰；开飞行模式再开？不用 —— 但要关掉其他 App 的通知

## 剪辑注意

- **不要**加花哨转场；每段直接硬切
- 字幕**手打**，别用自动识别（会认错"1 号楼 201"这类关键信息）
- 结尾仓库地址**停留 ≥3 秒**（观众要扫二维码/记名字）

## 备选素材（如果某段录不到）

- 她主动消息 → 可用**桌面挂件气泡**代替（同一套逻辑，视觉上更清楚）
- `/llm-preview` 面板 → 可用 `hubctl dump --redact` 的输出截图代替
- 没有单片机 → 跳过，别硬凑
