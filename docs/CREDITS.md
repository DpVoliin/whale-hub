# 第三方数据源与署名

本项目代码是 MIT；但**它调用的外部数据源各有自己的许可与使用条款**，这里逐条写清。
（只列真正会用到的那几个；没有引入任何第三方**代码**依赖 —— 中枢与说话层都是纯标准库。）

## 天气：主源「中国天气网」，兜底 Open-Meteo

天气**不是一个源**，是"主源 + 兜底"两级：

### 主源：中国天气网（`weather.com.cn`，中国气象局数据）

- 用途：`hub.py` 的 `weather_from_official()` / `wx_search_city()` —— 一次拿到**实况 + 多天预报 + 天气预警 + 生活指数**。
- 怎么取的：请求它**公开的网页接口**（`http://d1.weather.com.cn/weather_index/<城市代码>.html`，
  带 `Referer: http://www.weather.com.cn/`），从返回文本里抠出 JSON。**不需要 key、不需要账号**。
- 范围：**城市级**（默认广州 `101280101`，可在 `hub.json` 改；`hubctl city <城市名>` 可查城市代码），
  不涉及手机定位，也不上报任何用户标识。
- 频率：随简报/定时任务，约每几小时一次（不是轮询）。
- ⚠️ **这是公开网页接口，不是带许可的开放 API**：本项目只在**个人自用**场景下调它；
  如果要**商用或对外提供服务**，请自行向中国天气网/中国气象局确认授权，或改用有明确商用条款的数据源。
- 数据权利归 **中国气象局 / 中国天气网**。

### 兜底：Open-Meteo（国际模式，免 key）

- 什么时候用：上面的主源**全部失败**时才退回（离线兜底，不会让天气字段变空）。
- 数据许可：**CC BY 4.0** —— 官方要求给出来源署名，并说明是否做过修改。
- 免费层：**仅限非商用**，约 10,000 次/天、600 次/分钟；无可用性承诺。
- 官方原文：<https://open-meteo.com/en/terms>（"Non-Commercial Use"段）、
  <https://open-meteo.com/en/pricing>（"licenced under Attribution 4.0 International (CC BY 4.0)"）。
- **本项目做的事**：取几个字段，按内部码表翻成中文短语（`weathercode` → "雷阵雨"），只留"天"粒度 ——
  这属于对数据的修改，按 CC BY 4.0 一并声明。
- **署名**：天气兜底数据来自 **Open-Meteo.com**（CC BY 4.0）。

## 字体

界面所用 **HarmonyOS Sans SC** 的许可与署名要求，见仓库根目录的
`HarmonyOS-Sans-LICENSE.txt` 与 `desktop/使用说明.md` 的"字体与第三方许可"一节
（允许嵌入随软件分发、须保留版权声明、**不得单独再分发字体文件**）。
因此**字体文件不进本仓库**，只在发布包里随 exe 一起嵌入。

## 没有引入的东西

- 没有任何 GPL / LGPL / AGPL 的**代码**依赖（这类是传染性许可，与本项目的 MIT 不兼容）。
- 中枢与说话层**零第三方 Python 依赖**（只用标准库）—— 这是刻意的设计约束，不是巧合。
  需要第三方库的场景走 `hub/ext/` 外挂扩展，由使用者自己安装与承担其许可责任（见 `docs/EXTENSIONS.md`）。
