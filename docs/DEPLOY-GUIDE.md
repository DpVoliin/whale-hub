# 部署图文教程（照这个走，半小时能用上）

> 目标读者：**没写过代码也能照着做完**。每一步都有"你应该看到什么"，对不上就是那一步没成。
> 遇到报错先看最后一节「常见报错对照表」。

---

## 需要准备什么

| 东西 | 说明 | 花费 |
|---|---|---|
| 一台常开的机器 | 家里旧电脑 / N100 小主机 / 云主机都行，4C4G 足够 | 0～几十元/月 |
| 安卓手机 | 用来装采集器（**iOS 不在计划内**）| — |
| 一个模型 API | 她"说话"要用；便宜档就够（日常调用量很小）| 按量，一般几块钱/月 |

**不需要**：公网域名、备案、数据库、Docker（可选）。

---

## 第 1 步：把中枢跑起来

```bash
git clone https://github.com/DpVoliin/whalecare && cd whalecare
python3 hub/hub.py
```

**你应该看到**：
```
=== hub v0.x.x 启动 === 端口 11440  token ab12…9xyz（完整值在 hub.json）
```
> token 打码了，完整值在同目录的 `hub.json` 里 —— 后面手机要填的就是它。

用 Docker 的话等价于：
```bash
docker compose up -d && cat ./data/hub.json
```

## 第 2 步：让它常驻 + 能用手机连上

1. **常驻**：`bash hub/tools/onestep_deploy.sh`（写一条 cron，掉线自动拉起）
2. **网络**：
   - 只在局域网用 → 手机填 `http://<机器的局域网IP>:11440`，直接跳到第 3 步
   - 要在外面也能用 → 需要公网端口。**两种做法**：
     - **推荐**：WireGuard / Tailscale 组虚拟内网（仓库里有 `hub/tools/mcu_tunnel_setup.sh` 可参考），中枢**不暴露在公网**
     - 或者开放 `11443`（HTTPS，自签证书，App 端固定证书）—— 别开明文的 11440 到公网
3. **验证**：手机浏览器打开 `http://<IP>:11440/health` → 应看到一串 JSON

## 第 3 步：装采集器，填两个值

下载 APK 装上，打开后填：

| 填什么 | 从哪来 |
|---|---|
| **服务器地址** | 第 2 步的地址，如 `https://家里IP:11443` |
| **token** | 第 1 步 `hub.json` 里的 `token` |

然后**逐个授权**（每个都要手动点，安卓不给 App 自动拿权限）：

| 权限 | 为什么需要 | 不给会怎样 |
|---|---|---|
| 通知使用权 | 读健康 App / 音乐 / 订单的**通知** | 健康、在听什么、订单 全都没有 |
| 使用情况访问 | 读屏幕时长与 App 分类 | 没有屏幕/游戏/App 时长 |
| 日历（可选）| 读日程 | 没有日程相关提醒 |
| 蓝牙（可选）| 读耳机/手表电量 | 没有蓝牙电量 |

**你应该看到**：设置页顶部出现"上次上报 xx 秒前"。

## 第 4 步：让她开口（说话层）

她"说话"这一段跑在**任何一台常开的机器**上（中枢那台也行）：

```bash
export WHALE_HUB="https://你的中枢:11443"
export WHALE_TOKEN="你的token"
export WHALE_CA="/path/to/hub.crt"      # 自签证书要指定，否则中继/说话层拒绝启动
python3 speaker/whale_speaker.py
```

**你应该看到**：日志里出现 `[speak] 启动：会拿主意的嘴`。

出口接微信需要网关的 webhook（见 `docs/ARCHITECTURE.md`）；不接微信的话，
她的话会写进中枢的待发队列，用 `hubctl` 或桌面挂件取。

## 第 5 步：验收（3 条命令）

```bash
python3 hub/hubctl.py status        # 有没有数据进来
python3 hub/hubctl.py today         # 今天她看到什么
python3 hub/hubctl.py interruption  # 她开口的节奏与接受率
```

## 常见报错对照表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| App 一直"上报失败" | 地址/token 填错；或自签证书没固定 | 用 `/health` 在手机浏览器验一次；HTTPS 要带证书 |
| `token 不对` | `hub.json` 里的值复制漏了字符 | 重新复制完整值（别带引号） |
| 手机连不上但电脑能连 | 手机和中枢不在同一网段 / 防火墙 | 检查局域网 IP、路由器隔离、系统防火墙放行端口 |
| 健康数据一条没有 | 通知使用权没给，或厂商健康 App 不推通知 | 授权后让手表同步一次；**厂商改通知格式就可能断**（已知脆弱点）|
| 她一直不说话 | 免打扰时段（23–7）/ 期望效用 gate 判定不划算 | `hubctl interruption` 看理由；临时测试可设 `WHALE_IGNORE_QUIET=1` |
| 数据"卡在昨天" | 手机被系统冻结了后台 | 设置 → 应用 → 耗电管理 → 允许后台高耗电 + 允许自启动 |
| 说话层报"拒绝启动：没有可用的 CA 证书" | 自签证书没指定 | `export WHALE_CA=...`（这是**故意的**，不允许默认裸奔）|
