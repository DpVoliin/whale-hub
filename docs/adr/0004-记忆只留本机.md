# ADR 0004：记忆与反馈只落本地，进模型的只有检索结果

**决定**：`episodes`（她说过什么/发生过什么）与 `feedback`（✓/✗）只写自己服务器的 SQLite；
`llm_context` 里放的**只是检索出来的那几条摘要**，不是整库、也不是原文。

**为什么**：私人系统的记忆天然敏感（"我奶奶的高血压药"这种）。全量交给模型 = 把隐私面交给
一个你不可控的第三方。检索式注入让"记得住"和"不外泄"同时成立。

**配套**：`/llm-preview` 能逐字核对"到底给模型看了什么"；脱敏有回归测试集
（`tests/test_privacy_regression.py`），换模型/改 prompt 都跑一遍。
