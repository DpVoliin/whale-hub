# ADR 0003：人设包可替换；非原创素材不进公开库

**决定一（人设）**：人设从"散在两处"（中枢配置 + 说话层角色卡）收拢成 `personas/<名字>/`，
两侧读**同一份**（说话层从中枢 `/persona/card` 取）。切换 = 改 `persona_pack`。

**为什么**：收拢前两处口径不一致——中枢教她"动作要具体（递水/把灯调暗）"，角色卡却明令
"她是 AI 不许物理动作"。**两处不一致她就会说假话。**

**决定二（素材）**：仓库 MIT，但形象图**非原创**，不进公开库；公开库只留
占位图生成脚本 + 字体许可文本 + 自制音效。真素材放私有库（`whale-assets`），并写明"不随软件分发"。

**为什么**：把版权风险塞给每个 clone 的人，是最容易忽略的一种"对外伤害"。
