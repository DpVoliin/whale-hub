# ADR 0001：单文件交付 + 源码片段合并

**背景**：源码涨到 3000 行，单文件越来越难维护；但"单文件、clone 即跑"是公开卖点。

**决定**：源码切进 `src/whalecare/` 13 个片段（按职责），`tools/build_single.py` 按序合并成 `hub.py`。

**为什么不是 Python 包**：拆成包就丢了"一个文件跑起来"这个差异点。片段合并（SQLite 的做法）两头都要。

**代价与验证**：切分是**纯机械切片**，所以合并结果与原文件**逐字节相同**（`cmp` 可证），
等价性不靠"感觉没坏"。`build_single.py` 还会断言关键函数与 `Handler` 方法都在**模块级** ——
曾经把方法抽成函数时留在 class 内部，后面的方法变成它的嵌套函数（语法合法、`py_compile` 通过），
但 Handler 少了方法、接口直接崩。
