鲸鲸 · 桌面（WhaleDesk 0.1.0）
=====================

双击 WhaleDesk.exe 就跑，不用装 Python。
（左键点她：换一张表情 + 冒个气泡；不会弹窗）

第一次：右键她 →「数据与设置…」→ 填【中枢地址 + Token】和【DeepSeek API Key】→ 保存。
（没填之前，气泡里写「未填 Key / 连不上中枢」——不是坏了。）

气泡会往后翻：① 余额/下一节课/屏幕时长 ② 中枢算出来的提醒 ③ 关心（天气/电量/在听/快递/电脑体检…）④ 闲聊

换形象：把你的图丢进这个文件夹里的 assets\ ，覆盖同名文件即可，不用重新打包。
   pet.png        常驻站立
   pet_flip.png   贴左吸附时的镜像版（把 pet.png 水平翻转就行）
   pet_sleep.png  打盹（画小一团、重心偏下）
   exp_<名字>.png 点一下随机换的表情（同时要有 exp_<名字>_win.png）
   ⚠️ 背景必须是纯 #010203（Windows 靠这个色做透明，只认精确匹配），
      尺寸/留白一致、脚踩同一条基线，否则会出现黑边或换姿态时跳位。

电脑采集（同一个 exe）：右键 →「电脑采集」→ 开关采集 / 上报状态 / 隐私预览（看会传什么给鲸鲸）。

出问题把 whale-desk-log.txt（和 exe 同目录）发我。

详细说明见 使用说明.md
