# 鲸鲸 · 桌面（WhaleDesk 0.1.0）

双击 **WhaleDesk.exe** 就跑，不用装 Python。

**一个 exe = 两个功能**：桌面挂件 + 电脑使用情况采集（同一进程、一份配置、一个开机自启）。
采集那部分在右键菜单 →「电脑采集」里开关和查看。

---

## 一、她会做什么

| 你做的事 | 她的反应 |
|---|---|
| 平时（不理她） | **桌面上只有一个形象，零数字** |
| **点一下** | 形象**随机换一张表情**（脸红 / 高兴 / 害羞 / 惊讶 / 生气 / 困，约 1.2 秒后回到常态），同时冒一个气泡 |
| **再点** | 气泡顺着队列往后翻：**第 2 泡是提醒**（中枢算出来的，不只是课表）→ **第 3 泡是「关心」**（天气 / 手机电量 / 闹钟 / 在听什么 / 连续活跃 / 温湿度 / 快递 / 游戏 / 电脑体检）→ 第 4 泡随机闲聊。翻到最后一泡再点 → 收起气泡 |
| **按住拖动** | 换成「被拎起来」的姿态跟着鼠标走（需要 `pet_drag.png`；没这张图就沿用站立姿态），松手时**自动吸附到最近的屏幕边**（含角落）；拖到屏幕右缘时气泡会**自动翻到左边**，不会飞出屏幕 |
| **拖到左缘吸附** | 整体**水平镜像翻转**（带 0.18 秒翻转动画） |
| **右键** | **自绘深色圆角菜单**（跟气泡同一套外观，悬停一行淡高亮，"开"状态左侧一条绿条）：形象大小 / 贴边吸附 / 贴左镜像 / 点按推进气泡 / 点按换表情 / 音效 / 电脑采集（上报状态·隐私预览）/ 数据与设置 / 打开配置 / 开机自启 / 桌面透明 / 退出 |
| **闲置一段时间** | 缩成一团打盹，整窗淡到 25% |
| **点一下打盹的她** | 直接给数据（不用点两次） |

气泡 20 秒没再操作就自己收起来，不占你桌面。

**「下一节」什么时候带日期**：今天/明天的课只显示时刻（如 `下一节 08:00 电气控制与PLC`）；
**更远**的课会自动带上日期（一周内 `周日 14:00`，超过一周 `09-27 10:00`），不会让你误以为是今天的课。

**左键只做「翻气泡 / 换表情」这两件事** —— 不会有任何弹窗。

**音效**：默认开，点一下是很轻的「啵」（右键 → 音效 可关掉）。
两个音是用纯 Python 算出来的波形（`tools/make_sfx.py`），体积各约 10KB，无第三方音频素材。

## 二、第一次要做的三件事

**① 填中枢地址 + Token**（挂件的数据都来自你自己的中枢）
右键 → **数据与设置…** → 在 `中枢` 一节填 **地址**（如 `https://你的域名或IP:11443`）和 **Token**（中枢 `hub.json` 里那个）→ 保存。
> 没填之前，气泡里那几行会写「未填 Key / 连不上中枢」—— 不是坏了。

**② 填 DeepSeek Key**（查余额用，Key 只存在你这台电脑上）
右键 → **数据与设置…** → 填 `DeepSeek API Key` → 点「测试连通」→ 点「保存」。

**③ 开机自启**（可选）
右键 → **开机自启**（会在启动文件夹放一个 `WhaleDesk.vbs`，纯 ASCII，不弹黑窗）。

## 三、换形象 / 加表情（不用重新打包）

把图丢进 **exe 旁边的 `assets\` 文件夹**，覆盖同名文件即生效。

### 姿态图（4 张）

| 文件名 | 用途 | 要求 |
|---|---|---|
| `pet.png` | 常驻站立 | 见下 |
| `pet_flip.png` | 贴左吸附时的镜像版 | 可以用图片工具「水平翻转」`pet.png` 得到 |
| `pet_sleep.png` | 打盹 | 建议画得小一团、重心偏下 |
| `pet_drag.png` | 拖拽时「被拎起来」 | 可选；缺这张就沿用站立姿态 |

> ⚠️ **Windows 上会优先读同名的 `*_win.png`**（拍平到键控色的那份），没有才回落基础图。
> 这两份必须成套替换 —— 只换 `pet.png` 而留下旧的 `pet_win.png`，看起来像"换了没生效"。

**图的硬要求**（不满足会出现黑边或跳位）：

1. **背景必须是纯色 `#010203`**（Windows 靠这个颜色做透明键控，只认精确匹配）。
   出图时用**纯绿幕/纯色幕**再拍平到这个色值，别留半透明边缘 —— 半透明像素键不掉，人物周围会有一圈黑边。
2. **各图尺寸一致、四周留白一致、脚踩在同一条基线上**（她换姿态时不会「跳」）。
3. 现在这版素材是 **129×200**（站立/镜像/拖拽）、打盹 **130×170**，可以照这个规格画。

### 表情图（点一下随机换）

点一下会从 `pet.expressions` 里随机抽一张，**1.2 秒**后回到常态。

**换/加自己的表情**：

1. 出图 → 存成 `exp_<名字>.png`（名字随意，例如 `exp_proud.png`）
2. 丢进 exe 旁的 `assets/` 目录（**同时**要有 `exp_<名字>_win.png`，拍平无 alpha 版）
3. 打开 `whale_desk.json`，把名字加进 `pet.expressions`：
   ```json
   "expressions": ["blush", "happy", "shy", "surprised", "angry", "sleepy", "proud"]
   ```
4. 重启挂件。

> · 名字不在 `expressions` 里不会被抽到；文件不存在的名字会自动跳过，不会报错。
> · 显示时长改 `pet.expression_ms`；不想要这个功能就把 `click.expression` 设成 `false`。
> · 自己处理素材时，`tools/make_pet_from_raw.sh` 能一次做完「抠底 → 裁轮廓 → 缩放 → 生成软边版 + Windows 拍平版」，
>   它自带姿态/表情两类输入的用法说明；`tools/check_expressions.py` 用来体检（真表情 vs 站立图调色、超宽、键控色）。

> 想调形象大小：右键 → 形象大小（120 / 160 / 200 / 260 / 320 px），实时生效并记进配置。

## 四、配置与数据

- 配置文件：**exe 旁边的 `whale_desk.json`**（第一次运行会自动生成）
- 数据来源：
  - **中枢**（你自己填的地址）—— 今日课程、下一节课、今天的提醒、屏幕/睡眠
  - **DeepSeek 余额**（`https://api.deepseek.com/user/balance`）—— 要你自己填 Key
- **上传加密**：中枢走 HTTPS + **证书固定**（只信 exe 旁 `assets/hub.crt` 那张证书）
  → 把你中枢自签的那张 `hub.crt` 导出、放到这里即可；连不上时才退回明文 `:11440`（可关）
- 刷新：默认 60 秒一次；点一下她、或右键「刷新一次」可以立刻刷
- 退出时会记住你把她放在哪，下次开机还在那

## 五、已知边界（先说清，免得你以为坏了）

- **形象/表情就是你自己那套图**：换图只要往 `assets/` 里放同名文件，不用重打包。
- **文字不跟着镜像**：Tk 画不出反向文字，所以贴左吸附时**只有形象翻转**，气泡里的中文照常正着写。
- **开机自启的 .vbs 是纯 ASCII**：Windows Script Host 按 ANSI 读脚本，写中文会乱码。
- **界面观感受系统影响**：不同壁纸下的边缘观感、右键菜单手感，以你机器上的实际效果为准。

## 六、电脑采集（同一个 exe 里的第二个功能）

右键 →「**电脑采集**」，三个条目：**开关采集** / **上报状态…** / **隐私预览（会传什么给鲸鲸）…**

| | 内容 |
|---|---|
| **会上报的** | 只有聚合量：`screen.active_minutes`（活跃分钟）、`screen.idle_minutes`（空闲分钟）、`app.<类别>_minutes`（各类别分钟）、`pc.continuous_active_minutes`（连续活跃分钟）、`pc.disk_free_percent`（系统盘剩余%）、`pc.mem_percent`（内存占用%）、`pc.uptime_hours`（开机时长）、`pc.window_switches_today`（今日窗口切换次数） |
| **绝不上传** | 窗口标题全文 · 进程路径/文件名 · 网址/文档名/搜索词 · **按键内容（不是键盘记录器）** · 截图 · 剪贴板 · 磁盘上的文件名 |
| **标题** | 只在**内存里**用来判类别（"学习通 - 作业"→ study），判完即弃，不落盘、不进日志 |
| **传输** | 只有 **HTTPS + 证书固定**（只信 `assets/hub.crt`），**没有明文回退**；连不上就攒在本地 |
| **本地待发队列** | Windows **DPAPI 加密**（绑你账号），别人拷走文件也解不开 |
| **自己核对** | 点「隐私预览…」—— 它显示的就是**上传的完整内容**，也就是 AI 唯一能看到的东西 |

采到的用处：连续活跃到 **50 分钟**，中枢会往你微信推一条「站起来抻一下」；系统盘快满 / 内存吃紧 / 开机太久，她也会顺口提一句（这些指标她也看得到，但只看到百分比和次数）。

想改类别表（哪些软件算哪类）：配置文件里的 `collect` / 类别表在采集侧，改
`whale_pc.json`（首次运行后同目录会生成一份）。日志在 `whale-pc.log`。

## 右键菜单里的「刚刚那条：说得对 / 别说」

她主动说的话，你可以在挂件上右键 → 用这两项给她反馈：

- **说得对**：这个场景该说 → 她会更愿意在类似时候开口
- **别说**：这条不该说 → 她会收敛

反馈会发到中枢 `/feedback`，喂进她的节奏学习（命中率高会让每日上限放宽，低则收紧）。
**不点也没关系** —— 挂件只负责把反馈送出去，学不学、怎么学在中枢，送不出去也只记日志、不影响挂件本身。
